# 前向试用与有范围审图

本报告保留首次前向试用时的发现与状态。随后获授权修复 compose 规则与 C03 引用，并完成九技能结构验证和 SVG 扫描器兼容修复；后续变更见上一级 `skill_validation.md/json`。首次试用的实际路线仍仅为下述七模块。

## 实际任务与路由

本次从空白开始为光电器件任务制作一张图，未打开或复用技能包的现成 DEMO 图及数据。任务对象为 3 批 × 5 个独立器件、glass / ITO / active film / Au 层序、处理前后性能—带宽权衡；没有真实数值、厚度或动力学速率。

实际加载：`sci-figure-director → sci-figure-data + sci-figure-device + sci-figure-mechanism + sci-figure-compose + sci-figure-color → sci-figure-review`。其中 mechanism 用于判定证据边界，并未强行输出机制面板。未加载 process 或 image，因为任务没有过程时间序列、显微或场图资产。

另读了 director 的 brief-contract，data 的 scientific-checks/task-cases，device 的 geometry-and-export/routes-and-evidence，compose 的 editable-production/layout-strategies，color 的 color-semantics，review 的 review-report/svg-scan。没有全量加载文献库，没有开展新文献检索。

两种布局草图见 `layout_routes.svg`：一是紧凑结构区加三批小多图，二是结构顶带加汇总散点。选前者是为了直接显露批次身份并减少同图配对线拥挤，数据面积明显大于器件示意。选择 Python 标准库生成 SVG、Inkscape 渲染；无安装、发布或外部写入。

## 实际发现与修复

1. **首版左侧说明侵入纵轴区。** 依据是实际打开的 300 dpi PNG；review 机械扫描当时没有 findings。长说明改为短行，纵轴标题向左移动，再用 Inkscape 实际字形包围框核查，最终 58 个文字对象无互相交叠、无越出画布。此事证明目视渲染是必要步骤；扫描器文档本来就声明不检查遮挡，因此不是其契约缺陷。
2. **首版两组模拟端点过近，配对容易混淆。** 根据成图修订了自造 DEMO 的演示值间距，保留每批 5 个配对，没有删除点。当前成图可逐一辨认。真实研究值不能为了好看这样改数，届时应通过表示方式、局部放大或布局处理；本次变化只限明确标注的自造演示数据。
3. **颜色不能单独可靠区分所有条件。** 实际运行 `palette_audit.py --colors '#697680' '#176B7B' --background '#FFFFFF'`。原始近似 ΔE76 = 19.278，protanopia 模拟为 8.683，灰度为 7.286；不据此宣称“色盲安全”。实际图采用空心圆与实心菱形的冗余编码，灰度整图已打开检查，前后状态仍可区分。

## 三类有限结论

**科学语义。** 已核对层序、配对身份、3 批各 5 个独立器件、两个条件各 15 行、单位标签、共同轴限与全部 30 个端点。端点均落在显示轴限内。图中明确 DEMO、未知厚度、泛化性能指标与配对假设。只把用户给出的稳态光谱变化和稳定性提高写成定性信息，未绘制转移加速箭头、能级或速率。未核验真实器件数据、测试工况或机制；这是一张演示图。

**视觉。** 实际打开 300 dpi 全图、180 mm 物理画布的 1200 px 缩小预览和灰度整图。检查了面板 a–d、图例、箭头端点、层序标签、轴名和底部 DEMO 声明。修复后未见原先的拥挤和文字碰撞。最小文字近似 7.37 pt、最大 10.20 pt，适用于当前 180 × 104 mm 草案；未将其称为任何期刊的字号合规认证。

**可编辑交付。** SVG 有 58 个 live text、34 个命名组，零 image 节点和零外链资产；每个器件配对有稳定 sample ID，数据点、配对线和材料均为独立矢量对象。运行主脚本、PNG 导出、review 扫描和颜色诊断均成功。`svg_scan.json` 的 findings / uncertainties 均为空，但仅视为机械清单。`runtime_checks.json` 另记录 Inkscape 字形包围框无文字交叠或裁切。没有验证第三方编辑器导入后的文本重排。

## 技能实际帮助与暴露的限制

技能的可观察作用是：把“高级一点”转为权衡与批次任务；将数据表示选为配对小多图；把未知厚度落为非比例二维剖面；让机制模块决定省略没有速率证据的因果路径；强制实际打开导出，而不是只相信 SVG 扫描。它们没有要求英雄式 3D、大机制图或固定六面板。

本路线未发现需要立即修复的科学语义规则缺陷。初始读取 color 时其脚本与 palette 资产仍在补写，后续出现后本次已实际运行，所以不把这个已消除的中间状态记为最终缺陷。需要保留的能力边界有两项：机械扫描不负责实际字形遮挡，颜色诊断只测色块，均仍依赖成图检查；这些边界已经被技能准确声明。

较轻的设计摩擦是 compose 无条件要求至少比较两种布局，而 director 允许简单单图直接制作；本例为复合图，制作两张低保真草图是合适的，但应用到简单坐标图时可能造成额外工作。建议未来把 compose 的双布局要求也限定为复杂、模糊或重排任务。没有在本次修改技能。

本次只试用一个器件—统计混合路线，不能外推为所有图类都不会模板化，也没有检验三维、显微、光路、频谱或时间序列分支。
