# 互指顶电极与埋藏界面：原创三维教学示例

这是一个 **DEMO／非实测／不按物理比例** 的光电导器件空间示意。两套同材质的顶电极各含一条母线、四根指状电极和一个圆形端子。每套电极内部连通，两套之间保留间隙；连续的半导体层覆盖介电层和支撑基底。前缘无电极的区域被真实几何切去一角，露出层间界面。切口不穿过电极网络，避免把教学剖切误解为电极断裂。

## 三维在这里解决什么问题

读者需要同时理解两个方向的关系：平面内交错的电极归属，以及厚度方向上半导体—介电层—基底的接触顺序。斜视总图保留完整的互指图案，切口让埋藏界面具有可见边界；近景来自同一个模型的第二台正交相机，可核对边缘和材料位置。三维的任务是连接这两类空间关系。金属表面采用较高粗糙度的柔和材质，低反光保留指间隙；没有以粒子、光晕或未经计算的场线填充画面。

主图和近景中的色彩仅区分部件。A、B 都使用同一种金色金属材质，不暗示两种不同电极材料。层厚被放大以便阅读，图中没有比例尺。标签、引线和文字是独立的 SVG 矢量对象；引线端点由实际相机投影计算，并非凭空摆放。模型保留原生网格、两套独立电极对象、三层切口网格、材质、灯光和两台相机。

## 尚未定义的内容

本示例不指定半导体化学成分、电极功函数、接触势垒、掺杂、耗尽层、实际膜厚、制程可行性、偏压、光照波长、载流子分布或光电流。它没有求解电场，也没有提供性能预测。图中间隙与厚度均为任意教学单位，金属边缘的小倒角和材料粗糙度也不是测量结果。它不复刻任何论文的器件或作者视觉风格。改用于真实研究时，需要由研究者提供上述与科学问题相关的实际信息。

## 文件与编辑

| 文件 | 用途 |
|---|---|
| `advanced_device_demo.blend` | 可重新打开的原生三维源文件；五个实体网格、两台相机 |
| `advanced_device_demo.py` | 完整生成脚本；几何、材质、相机、渲染、投影标注和组合 SVG |
| `advanced_device_parameters.json` | 几何、视角和证据边界；尺寸没有物理单位 |
| `advanced_device_labels.svg` | 独立透明矢量标签覆层 |
| `advanced_device_preview.svg` | 自包含图版；嵌入两张渲染图，标签仍可编辑 |
| `advanced_device_preview.png` | 便于预览的完整图版 |
| `advanced_device_overview.png` / `advanced_device_interface.png` | 两台相机的透明背景原始合成渲染 |
| `verify_native.py` / `native_verification.json` | 重新打开 `.blend` 后的网格连通、流形性和相机检查 |
| `advanced_device_reopened_check.png` | 从重新打开的原生文件再次渲染得到的总图 |

在 Blender 4.5 中重建：

```bash
blender --background --factory-startup --python advanced_device_demo.py -- --out /absolute/output --render
```

复用导出的参数文件时加上 `--params /absolute/path/advanced_device_parameters.json`。该选项复用几何和视角字段；图版文字位置仍可在 SVG 中按构图调整。图版是空间教学示意，修改参数后应重新检查电极间隙、切口与电极是否相交、层顺序和标签端点。脚本含基本几何断言，不替代物理验证。

用 Inkscape 将自包含矢量图版导出为 PNG：

```bash
inkscape advanced_device_preview.svg --export-type=png --export-filename=advanced_device_preview.png
```

## 已实际完成的检查

使用便携版 Blender 4.5.0 生成并渲染两个视角；实际查看总图、近景和标签合成图后调整引线，避免文字被引线穿过。原生文件随后重新打开，并从保留的总图相机再次渲染。网格检查要求两套电极各为一个连通实体、五个实体均无非流形边，且保留两台相机；结果见 `native_verification.json`。这些检查证明源文件可编辑且几何可用，不证明真实材料或器件行为。

所有降噪仅作用于本例新生成的 Cycles 合成渲染。整个示例没有使用实验图像、测量数据或生成式实验像素。
