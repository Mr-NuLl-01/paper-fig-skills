# 几何与导出

## SVG剖面

建立对象ID、材料、位置、尺寸、单位、接触表；真实尺寸和显示尺寸分列。用viewBox内明确坐标映射绘制路径、孔洞和边界；材料、界面、测量体积、路径、文字、尺寸线分别命名组。对被夸张的薄膜写thickness exaggerated，局部放大有源框与独立尺度。剖切位置在整机上有切线，爆炸图保留原位装配关系。

字体保留文本与记录字体名，出版副本可转路径；不要只交一张烘焙文字的PNG。标签引线不跨越关键界面，箭头起止点应能跟踪。尺寸未知时不要从示意图面反算。

## 可选三维

| 对象 | 路线 | 保留信息 |
|---|---|---|
| 电极、膜、盖片 | 独立mesh/CAD实体 | 层厚、接触、对象名 |
| 光路、管路 | 曲线及横截面 | 起止点、方向与截面 |
| 爆炸装配 | 单独collection的变换 | 原位坐标及位移向量 |
| 剖切 | 保留Boolean/几何节点 | 完整实体和切面参数 |
| 晶格 | 从CIF/POSCAR生成 | 晶胞、元素、来源 |
| 数据表面 | 从体数据提取mesh | 阈值、分辨率、单位 |

正交相机适合接触/厚度，透视适合装配与实际空间，不默认一种。透明折射遮住薄层时先改剖切，不以假光路补解释。粗糙度与饱和度不编码相含量。

保存`.blend`、参数和相机，另导出无字透明渲染及独立SVG文字。GLB/OBJ检查单位、法向和材料。不能用手工雕刻补出数据孔洞或尖端。

## DEMO运行

便携Blender可用绝对路径运行：`blender -b --python scripts/device_demo.py -- --out /absolute/output`。脚本无外部依赖，建三个命名collection：assembled、exploded、section；默认渲染装配和剖切两个视图，保存源场景、参数与矢量侧视标注。所有图都标DEMO/非测量。将输出当原生资产示范，不当默认器件结构。

## 失败修复

薄层消失：局部剖面或有声明的厚度夸张。爆炸图接错：先验证原位接触，再位移。表面太耀眼：改光照或剖切，不修改数据几何。真实数据看似卡通：保留坐标与数据边界，不加“漂亮”的假孔洞。

## 三维引线定位
器件层标注优先从命名对象的明确边/面锚点，经最终相机投影得到二维引线起点。保持标签顺序与层序一致，换相机后重新投影，不能沿用旧像素位置。爆炸位移只改变展示位置；保存原位接触表。
