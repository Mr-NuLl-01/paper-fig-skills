# 体数据、连续场与时间矩阵

先读体素间距、单位、轴向、样区和物相。按问题选择切片、投影、等值面、体渲染、负空间或展开，含义不同。定位图标出切面，2D/3D共坐标；不同模态来自不同样本时不称同体素共定位。

| 路线 | 适用 | 保存参数 |
|---|---|---|
| 正交/任意切片 | 深度与内部关系 | 位置、法向、平均厚度 |
| 等值面 | 有阈值定义边界 | 阈值、插值、平滑、连通处理 |
| 体渲染 | 分布和遮挡 | 传递函数、透明度、相机 |
| 负空间 | 模板/孔隙/信号缺失 | 取反的量、阈值、身份依据 |
| 曲面/卷绕展开 | 沿复杂几何弱趋势 | 中心线、弧长、插值、掩模 |

数据表面平滑记录尺度，不抹真实尖端或孔洞；概念几何与数据几何分开命名。无需3D时可直接用切片。

连续场保持坐标、单位、范围和缺失值。单向量宜单调色阶，有物理中心的偏差用发散色，方向/相位用周期色阶并说明周期。无数值来源的概图不用测量型色条。截断、log、归一和扣背景登记；不为装饰补流线。

对象×时间矩阵保留ID、分组、采样时间、缺失和归一方式。按空间或预先说明统计量排序，不把人为斜线当传播速度。事件用一致阈值计算；个体独立归一时仅比较相对动态。平均线共用时间轴，另给个体分布。

## 实读案例与反例

B12图5：蓝色冰层片与灰黄模板骨架是互补空间，J1/J2/J3跨时间对应消除的尖端；不是两种独立实验。[来源](https://doi.org/10.1073/pnas.2210242120)。

B21图4：1H负空间仅显示电解液信号缺失，结合23Na才支持钠解释；气泡也可成暗孔。[来源](https://doi.org/10.1038/s41467-020-15938-x)。

B22图1/6：虚拟展开比旋转渲染更清楚地呈现卷绕电极弱趋势；X射线和中子来自两只电池，不能当严格共定位。[来源](https://doi.org/10.1038/s41467-019-13943-3)。

B24图6：千颗粒分十组热图与出口CO2共时间，显示平均值漏掉的异质性；每行归一，橙点来自阈值。[来源](https://doi.org/10.1038/s41467-020-18623-1)。

反例：只挑最规整晶粒证明均匀，删除无事件行，或按事件时间排序后称对角纹为空间传播。保留完整对象和排序记录，另给分布及代表轨迹。
