# 科学图像、体数据与场图

把图像当作证据，排版、注释和数据重建分别处理。保留原始文件、像素尺寸、采集信息和处理记录，再决定路线；只有发布图时可排版，但限制新的定量解释。

## 明确来源和任务

列样品/对象ID、模态、尺度、取向、时间/扫描方式、通道、单位、处理、ROI与来源。区分原始实验图、定量计算场、分割与概念示意。未知就写unknown，不凭图面推断真实分辨率和作者软件。

按[像素与注释合同](references/pixels-and-annotations.md)保护证据。禁止生成式修补、擦杂点、补边缘、平滑晶格、美化枝晶或AI重绘原始图。允许的数据处理也必须可追溯，不为匹配风格改变信号。

## 按问题选图版

| 要判断 | 主路线 | 关键条件 |
|---|---|---|
| 结构差异 | 配对图或条件矩阵 | 物理尺度、取向、强度可比 |
| 缺陷在哪里 | 全视野+inset+剖面 | 源ROI、标尺和坐标 |
| 对象如何演变 | 同视野帧+对象ID | 真时间、注册和扫描方向 |
| 化学身份 | 结构像+谱像+ROI谱 | 参考谱、拟合边界和残差 |
| 三维结构 | 定位图+正交切面 | 体素、单位、阈值和方向 |
| 个体异质性 | 对象×时间热图+分布 | 完整体、排序和归一 |
| 连续量变化 | 定量场+色条+剖面 | 来源、单位、范围和符号 |

体渲染、负空间、展开与场图细节见[体数据与时间](references/volume-fields-and-cases.md)。不固定网格、inset位置、背景、两色或全彩路线。

## 建立可比性

先比较像素和物理尺度，再裁切；相同像素宽度不等于相同放大倍数。比较强度需共同标定和范围；各自归一时明确只能比较相对分布/动力学。原始偏光色、元素通道与谱分解色有测量含义，不为风格统一替换。

ROI、箭头、编号、边界、色条、标尺和文字放独立矢量层。inset回溯源坐标，局部图不借裁切隐藏反例；轮廓叠加保存注册变换，不自由变形使不同结构看似相同。分割必要时并列原像，不能遮到无法核对。

## 色阶与三维语义

连续数值选可单调解码色阶，有物理中心的正负差值才用发散色，离散物相用类别色。缺失、低于/高于范围、掩模分别表示。幅度不能只凭颜色当高度，散射不能直接当含量，信号缺失不能独自完成元素鉴定。

三维先给切片定位，再选等值面、体渲染、剖切或坐标展开。灯光和相机帮助看清数据几何，不手工改孔洞和颗粒边界。负空间说明“哪种信号的缺失”，并以独立正证据支持身份。

## 检查与交付

目标尺寸检查细节、字、标尺与色条；核对每个ROI源图、对象身份、颜色解码、处理可恢复。图注说明样品、模态、尺度、颜色、扫描时序、归一/滤波/分割及推断限制。

交付原图嵌入且注释可编辑的SVG/PDF、预览和来源/处理清单；定量图附代码与数值映射，体数据附阈值、传递函数与变换参数。必要检查完成后结束，不为可逆排版增加无关重复测试。
