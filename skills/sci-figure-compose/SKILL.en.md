# Compose a scientific argument

Use the supplied objects, conditions, claim and constraints. Complete supported portions and explicitly leave missing evidence unresolved rather than adding an approval ritual.

Record final physical width/height, formats, required panels and real assets. Label size assumptions. Preserve layer order, adjacency, directions, state and scale status, and data files, columns, units, conditions and transformations. Each panel should answer a reader's question. Separate schematic, measurement, fit, simulation and literature comparison.

## Layout follows reading order
For a complex or ambiguous composition, compare two suitable organizations briefly, then execute the clearer one. Simple panels need no compulsory alternatives. Options include a main process axis, condition-by-measurement matrix, whole-object/section/inset chain, or unequal areas for decisive data. Device and data may coexist in a first figure; the device need not dominate.

Preserve shared viewpoints, limits, windows and directions where comparison requires them. Number or connect wrapped sequences. Rotating, cutting, unfolding or exploding a view must not change physical contacts, flow or electrical topology. See [references/layout-strategies.md](references/layout-strategies.md). Irregular layout is useful when content needs unequal space, not as decoration.

## Build separately, assemble editably
Generate curves and statistics from their numbers. Preserve photo/image crop provenance and calibrated bars. Use geometry tools when spatial accuracy matters and vector shapes for conceptual outlines. Do not guess author software. Generated textures cannot replace measurements, exact structures or final labels.

Use SVG or the user's native editable format. Separate structure, pixels, quantities, connectors, labels and legends. Preserve live text and scripts/data for quantitative paths. Verify links or embedded assets; see [references/editable-production.md](references/editable-production.md).

## Inspect and deliver
Render at final physical size and check reading order plus details: font points, arrows, scale bars, clipping, identity, transparency and legends. Quantity color bars need units; categories can use redundant shapes or line styles. Fix misleading or obscured evidence before aesthetic spacing. Use this repository's review module as needed, not an unrelated drawing skill.

Deliver editable master, preview, requested exports and necessary source assets/code. Explain the main layout choice, actual checks and remaining evidence gaps. Consult [references/examples.md](references/examples.md) selectively. Mechanical validation is not scientific proof.
