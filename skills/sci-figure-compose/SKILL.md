# 合成科学图

把一幅图组织成读者能够检查的论证。沿用用户已经给出的对象、实验条件、主张和交付约束；缺少关键数据时先完成可做部分，明确留下待补位置。不要把版式讨论变成额外审批流程。

## 1. 先建对象与证据清单

记录最终物理宽高、单/双栏或目标版面、需要的文件格式、必须出现的面板与已有真实资产。暂未提供的尺寸用明确假设完成首版。为每个对象保存材料/层序、空间相邻关系、方向、状态、尺寸是否按比例；为每条数据保存文件、列名、单位、实验条件和处理来源。

将每个面板写成一句读者要回答的问题，例如“腔体如何产生拉伸”“此散点量来自哪种细胞分割”。区分示意、测量、拟合、数值模拟、文献比较。设备与数据可共同出现在首图，设备也可以只占一小部分。

## 2. 用读序选择布局

遇到复杂复合图、读序不确定或需要重排的任务，快速比较至少两种适合的组织方法，再直接制作最合适的一种。关系清楚的简单单面板可直接制作，简述所选表示为何足以回答读者问题，不强制追加备选草图。短流程可沿一条主轴；多条件结果可按条件×测量方式排矩阵；多尺度机制可用定位框、剖面与局部放大；多器官/功能可按行安排输入、作用和证据；系统集成可将完整实体与制作细节分区。关键步骤或复杂数据可占更多面积。

保持比较所需的共同视角、轴限、图窗和方向。流程转行时用编号与箭头消除歧义。旋转、切开、展开和爆炸视图只能改变观察方式，不能改变实际层序、接触、流向或电连接。按图型需要读[layout-strategies.md](references/layout-strategies.md)，不要固定使用大主图、等分卡片、同一种底色或色板。

## 3. 分别制作，再可编辑合成

用真实数据重新生成曲线、散点、热图及误差表达；用真实照片和显微资产保留可追溯裁切与比例尺。需精确空间关系时用CAD或三维模型，示意轮廓用矢量；软件按工具能力选择，不能凭论文外观猜作者软件。AI位图可辅助概念纹理，不得生成测量数据、显微证据、精确结构或最终标签。

以SVG或任务指定的可编辑格式作合成主文件。分离结构、照片、数据、连接线、标签和图例等逻辑层；文本保持live text，数据图保留可重生成脚本/表格，图像链接或嵌入应与真实资产清单一致。按需读[editable-production.md](references/editable-production.md)。

## 4. 在最终尺寸验证

先以目标物理尺寸渲染，再检查一眼的读序和放大后的细节。检查标签在真实尺寸下的点数、曲线与比例尺的可见性、图像裁切、图例对应、箭头端点、相邻对象、颜色和透明度。连续场量使用有单位色条；类别除颜色外可补形状/线型。背景只为对比、环境或分区服务。

先修复影响科学解释或读数的问题，再处理空白与对齐。需要审查时调用`sci-figure-review`，并说明已经核验的范围；机械检查不证明机理成立，也不承诺期刊接受。

## 5. 完成交付

交付可编辑主文件、最终预览及被请求的导出；同时保留所需数据引用、脚本和真实资产。简短说明图的读序、主要取舍、已做核验和仍需数据确认的事项。按任务选用[examples.md](references/examples.md)中的验收条件，完成一次有范围的检查后停止无必要的反复打磨。
