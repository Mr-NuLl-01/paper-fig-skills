# 科研数据图：从比较任务选择表示

## 先建立数据约束

用一句话写出读者必须判断什么，例如“在相同亮度下哪组更热”“改性是否改变弱峰”“改善来自少数冠军还是多数批次”。检查数据、单位、独立样本/批次、测试条件、缺失值与来源。现有材料足够时直接执行；只有关键数值或对象无法确定才追问。没有实测数据时只制作明确标为DEMO的演示，不能把示意点当论文结果。

先保存原始值与变换记录，至少保留`sample_id、batch_id、condition、measurement_type`及与任务相关的时间、频宽、初始亮度/温度。把实测、校准、拟合、仿真和外推分别标记。未确认作者软件时写unknown；自行选合适工具重建，不推测“作者用了某软件”。

## 按任务选择图族

| 判断任务 | 优先尝试 | 不要自动替换为 |
|---|---|---|
| 性能随驱动/工况变化 | 有单位曲线、局部放大、适当log轴、对照工作窗口 | 只有峰值的柱图 |
| 重复性与批次差异 | 原始点/配对线、批次分面、分布或曲线群体与分位带 | 只有均值和未定义误差条 |
| 时域、频率与噪声 | 同步输入/输出共享时轴；幅频/相频/噪声谱各标频宽 | 一条“响应速度”指标 |
| 光谱与二维测量 | 原始谱/热图→抽取量→拟合；成对共享色域 | 裁掉弱峰后的平滑线 |
| 统计关系 | 散点、配对差、效应量与区间；保留层级 | 把相关性当因果的连线 |
| 参数折中 | 性能面、可行域、Pareto/条件散点及代表曲线 | 混单位雷达面积 |

只阅读当前图族所需的[图类案例](references/task-cases.md)；涉及寿命、log轴、双纵轴、归一化或统计结论时读[科学检查](references/scientific-checks.md)。

## 组织比较与视觉语法

先决定哪些量必须同轴、同尺度、同工况，再分配面积。允许单图、非均匀复合板、成对多行或二维矩阵；不固定面板数、hero图位置、两色白底或“Nature感”。让实验/仿真、控制/处理在对应位置，图像正交呈现；只为解释流程使用透视叠层。

定义对象色、状态符号和连续量色图。类别用可区分类别色；有序参数用有序色；正负量先确定比较符号还是绝对值。保留零点语义、色条范围与饱和值，不让同色跨图换义。真实发光颜色与热像伪色不是处理组身份。对阴影、背景分区、渐变和3D效果逐项问是否编码数据或结构。

保留长波尾、弱峰、离群点和不利组。log图不能静默删除非正值；双纵轴不能制造趋势一致；柱图使用真实基线，线图按问题选范围；断轴与归一化必须显式标注。小样本不依赖默认高斯拟合，配对数据保留配对，重复扫描不冒充独立器件。

## 重建、检查与交付

根据数据结构自主选择Python、R、现有工程或可编辑矢量工具；具体路线见[重建规程](references/reconstruction.md)。精确图表使用真实数据计算，不用生成式图片替代。直接运行绘图脚本，导出SVG/PDF和目标尺寸预览，实际打开检查文字、符号、单位、图例、裁切、色条和缩印可读性。

交付图、源数据/变换说明、绘图脚本与可独立阅读的图注。图注写明n的单位、误差定义、测试条件、归一化与实测/拟合/外推边界。检查跨面板颜色、轴名、索引及图注一一一致；科学目标已经可判断且无具体剩余风险时停止额外装饰。`scripts/make_demo.py`只演示两种不同任务表示，输出含DEMO水印，不能作为固定版式模板。

## 复杂视图补充

涉及三维热图平面堆叠、曲线瀑布图、复杂热图、体切片或非等大组合时，按需读取[专项说明](references/stacked-views.md)。先区分真实空间、测量条件与人为偏移，保留共同尺度、遮挡检查和可读的二维配套视图。
