# 颜色是可解释的编码

先判断颜色表达谁、多少、正负、方向、状态还是装饰。同一图的材料、条件和连续标量可以有不同作用域，但图例必须说明边界。已有化学元素/通道约定应检查冲突，不随意重置成流行色。

## 决策

| 含义 | 选择 | 明确事项 |
|---|---|---|
| 无序类别 | 分类色、形状、直接标签、分面 | 稳定ID→颜色，类别多时改变组织 |
| 有序强度 | 顺序色标 | 范围、单位、线性/对数规范 |
| 偏差/有意义中心 | 发散色标 | 中心值、两侧范围、归一化 |
| 相位/角度 | 周期色标 | 周期、起点、方向，矢量/无向轴区别 |
| 二变量 | 有二维图例的编码或分面 | 每轴含义与混色关系 |
| 显微通道 | 保留原始通道，可改LUT并记录 | 名称、独立图、合成、饱和 |
| 缺失/不适用 | 独立色、边界或明确空格 | 不等同零，不透明隐身 |

读 [references/color-semantics.md](references/color-semantics.md)。候选见 [assets/palettes.json](assets/palettes.json)：12组原创分类/示意起点和成熟连续色标清单。它们不是从论文提取的精确色值，也不是全部通过色觉检验的认证色。选色后看实际图，不能只看色块。

## 实施

实体、条件、状态和场量分别登记。同材料在器件、机制和数据图中尽量同色；有理由换色则说明局部作用域。颜色数量由任务决定，类别太多时改分组、分面、标签或交互，不无限加颜色。

线条和小点比大面积填充需要更强明度对比；淡色填充可配深轮廓，文字尽量独立深色。背景依数据选择，暗底荧光/体图与白底统计可共存。不要改变样本强度、独立自动缩放或添加假光晕换取通透感。

运行 `python scripts/palette_audit.py --palette indigo-copper --out <目录>` 输出色块、灰度、三种色觉模拟、L*、近似ΔE76和亮度对比；自选颜色用 `--colors '#颜色1' '#颜色2' --background '#FFFFFF'`。诊断仅提示问题，不能检测遮挡、尺寸、所有色觉类型和科学语义；ΔE76不是万能门槛。模拟在**线性RGB**变换后再编码为sRGB，记录色域裁剪。

连续色标优先选择已有科学库；检查当前安装可用项。不要把分类色卡插值成新连续色标。顺序L*单调、发散两侧和周期首尾分别检查，周期色标不能要求全程单调。方法和来源见 [references/diagnostics-and-sources.md](references/diagnostics-and-sources.md)。

## 交付

保存颜色登记JSON、规范/范围/中心/缺测配置、实际成图与诊断预览。保留色标和单位；按最终尺寸检查关键比较，必要时增加线型、符号、边界或标签。只报告实查场景，不称“万能色盲安全”。
