# 有范围的审阅交付

按任务复杂度取舍，通常一段范围、少量实质发现和三类有限结论足够，不强制填表。

## 范围

说明检查了哪个版本、哪些面板、哪个最终物理尺寸、哪些原始数据/图注/正文。区分整图实际查看、定向正文阅读与未核验方法/SI。若只收到导出图，不能声称检查了可编辑层或原始数据。

## 发现

每项回答：

- **发现**：例如“图a剖面把上层电极与下层液体画为接触，CAD显示中间有绝缘层”。
- **依据**：具体面板和给定CAD/数据/文字，不凭风格印象。
- **影响**：会误读电连接、改变定量比较，还是仅对齐问题。
- **修复/待补**：具体改动或需补的一项信息；有依据且已授权的修复直接完成。

## 三类结论示例

**科学语义**：已核对层序、流向和两列CSV单位；未独立复算统计方法或验证生物机理。

**视觉**：已在180 mm宽预览检查完整图和局部；修复图例遮挡和两处箭头歧义；原始显微图分辨率不足仍限制细节。

**可编辑交付**：SVG保留live text与分组，图像引用完整，数据图附重生成脚本；PDF导出已实看。未在另一个商业编辑器中验证字体替换行为。

不要把脚本无报错、资产哈希、模型自评或视觉精致作为科学有效性的证据。没有发现问题时使用“在上述范围内未发现……”，而非“全部正确”“符合顶刊标准”或“可以接受发表”。
