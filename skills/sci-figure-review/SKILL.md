# 审查科学图

先确定这次被请求检查的图、版本、主张、目标尺寸和已有证据。继续沿用用户已经授权的修复范围；发现排版或标注错误直接修复，缺少关键事实时保留可检查的具体问题。不要追加例行审批、综合评分或穷尽全部实验的门槛。

## 1. 阅读实际图与约束

打开可编辑主文件与最终导出，实际看整图，再以目标物理尺寸检查。读取图注、与图中结论直接对应的原始数据/正文段落和必要方法；若只收到图片，明确无法核验的数据与对象。下载、脚本输出和缩略图都不等于看过完整图。列明本次已看的面板、资产和来源范围。

## 2. 分开检查三件事

**科学语义**：对象、层序、连接、流向、观察轴、反应前后、驱动矢量是否一致？示意、测量、模拟与拟合是否能区分？单位、轴、色条、比例尺、采样时间、误差与重复定义是否与提供的来源吻合？设备与原始数据并存的首图，应追踪其测量关系，不能因“首图”而删去数据。三维效果、平滑曲线或显著性星号不能独立证明机理。

**视觉可读性**：读序和比较关系能否在最终尺寸辨认？文字、曲线、箭头、图例、图窗与裁切是否相互遮挡？连续场量和类别是否使用适当编码？同一对象换视图后是否仍可认出？亮/暗背景、透明度和多种颜色按实际对比需要评估，不套固定色板或版式。

**可编辑交付**：文字能否修改，层/对象是否可独立调整，图像是否缺链，数据能否从源表重生成？SVG、PDF、PNG之间是否丢字、缺图、改变裁切或重排？按需读[review-cases.md](references/review-cases.md)，分别报告三类判断，不以其中一类合格替代另外两类。

## 3. 使用机械扫描辅助定位

对SVG可运行：

```bash
python scripts/check_svg.py figure.svg --min-label-pt 7
```

字号阈值只在实际任务给出时指定，也可不指定。脚本报告物理画布、可识别的live text、近似最终文字点数、图像像素/放置尺寸、元数据存在性和本地资源引用；它不访问远程资源，不解析完整CSS/滤镜，不理解科学对象。复杂嵌套视口、字体替换、混合文字run等仍要渲染查看。完整边界见[svg-scan.md](references/svg-scan.md)。不要把“扫描完成”写成“图已科学验证”。

## 4. 修复并做一次针对性回查

先修复会改变科学解释或遮挡证据的问题，再处理对齐与观感。修改比例尺、样本数、连接或实验标注必须有依据；无法确认时精确指出需要哪项数据。只对修改区域和相关导出回查；不因无关假设扩大测试。涉及重构版式时可调用`sci-figure-compose`。

## 5. 给出有限结论

用“发现—依据—影响—修复/待补”说明实质问题，分别总结科学语义、视觉和编辑交付。写清没有核验的部分与残余限制，例如“仅核对这两列数据，未验证统计方法”“已检查层序，未独立验证材料机理”。附实际修改文件和预览，并指出最终尺寸。按[review-report.md](references/review-report.md)简洁交付；不要承诺顶刊标准、投稿成功或科学假说成立。
