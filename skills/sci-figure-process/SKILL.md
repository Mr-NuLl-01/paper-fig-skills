# 生长、反应与实验过程

从对象、边界和证据组织过程，不先选一排箭头模板。完成必要科学组织后直接制作，不把常规绘图选择变成额外用户门禁。

## 建立过程清单

写图要回答的问题，列样品ID、状态、操作、环境、时间原点、观测量和证据。分别记录同一样品连续变化、平行样品比较、实验步骤及推断微观事件。缺少真实时间只表达次序，等间距面板不暗示等时长。

读[语义与实施清单](references/semantics-and-delivery.md)处理时间零点、守恒和样品更换。保持原始证据的结论强度；本技能不独立确认论文全部机理。

## 选择路线

| 问题 | 路线 | 同时说明 |
|---|---|---|
| 实验怎么做 | 步骤或操作泳道 | 输入、输出、转移、条件 |
| 哪些物种/结构改变 | 状态框+物种账本 | 身份、去向、体系边界 |
| 多条件为何不同结局 | 分支或条件矩阵 | 干预不是时间 |
| 刺激与响应何时发生 | 共时钟分面 | 输入、响应、仪器延迟 |
| 核/晶粒/界面怎么移动 | 同视野帧+局部量曲线 | 对象ID、ROI、尺度、扫描时长 |
| 跨尺度如何连接 | 观测到概念的分层解释 | 放大关系、证据等级 |
| 哪类机制适用 | 条件/无量纲形貌图 | 边界与适用范围 |

不固定网格、两色、白底或全3D。路线可组合，但每种图形只承担明确任务；查[实读案例与反例](references/cases-and-counterexamples.md)。

## 先画对语法

让箭头分别表示操作、时间、物料流、可逆转化、测量路径或因果推断，并配必要文字。分支写触发条件，逆过程说明是否回到同一状态。数据优先共用绝对时钟；另用成核后相对时间时明确转换。仪器延迟及扫描慢轴进入图注，峰先后不直接等于因果。

画溶解、团聚、传质和相变前，列进入、离开、残留及换态物种。有定量来源才按数量/体积配平；没有则标schematic/not to scale。物种跨状态保持符号身份，不把不同相、价态或尺度因省事画成同一对象。

## 让证据进入构图

真实帧、实测曲线、计算与推断相邻但可辨识；图注逐面板写observed、calculated或proposed，不只靠虚线暗示。概念浓度线、能垒和粒子计数不得伪装为数据。图像不生成式修补，不为填齐时间帧补造事件。

先定义颜色表示身份还是物理量，再调风格。固定物种跨状态可识别，允许不同测量用不同色图；阶段背景、连续参数和物种色分别定义。线型、符号、形状和直接标签帮助辨识，不靠高饱和3D纹理代替科学语义。

SVG将状态、箭头、数据图、原图与注释分层，按样品和状态ID命名；Python/R沿用现有环境，不要求用户先选语言。可选3D输出原生状态/相机参数及独立矢量标注，不只交一段视频。

## 验收与交付

沿起点到终点核对样品、时间、物种、条件和证据。检查同时间对齐、示意标识、分支条件以及机制的不确定程度。目标尺寸下箭头不穿字，局部对象与图例可读。

交付SVG/PDF和预览，数据曲线附代码与映射，图注含阶段、时间起点、控制条件、比例及证据限制。作者软件未声明就记unknown，不能把本次建议工具归给作者。全部必要检查完成后结束，不为可逆排版增加无关重复测试。
