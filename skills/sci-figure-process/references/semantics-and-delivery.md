# 语义与实施清单

给每个面板登记`sample_id / state / intervention / environment / time_origin / time / observable / evidence`。给每条连线登记`meaning / condition / reversibility / evidence`。这是轻量组织建议，不强制用户填写表单。

| 关系 | 表达 | 不可默认 |
|---|---|---|
| 操作 | add/heat/wash和条件 | 各步等时 |
| 时间 | 真时刻或相对时间 | 多样本是同一对象 |
| 样品 | 样品ID和条件行列 | 左图自然变右图 |
| 状态 | 物种、相、形貌 | 示意是显微快照 |
| 物料流 | 体系内外及组分 | 箭头即证实反应 |
| 推断 | proposed/possible及依据 | 先后即因果 |

## 物种账本

列物种在哪、是否跨边界、是否换价态/溶剂化/相。知道反应式就检查守恒，未知不编配平式。球数/大小编码含量必须有来源；非定量图标可用固定数量并标illustrative。蒸发、洗涤和耗尽有明确去向。

## 时钟

记录绝对时间、对象首次出现、刺激起止及仪器传输。诱导时间用共同起点；增长律可重设起点但保留映射。扫描像素不同时间采集时，帧时长/方向/行时间进入解释。

## 证据与原生交付

逐步直接成像、间接谱、相关性与计算候选分开。实线/虚线仅辅助，图注能独立说明。不把suggests改为proves，不补画未知中间体。

SVG以样品/状态命名，原图、数据、模型、示意和标签分层。曲线从数值生成，保留处理参数；无数据不加误差棒。动画先保留可编辑状态与时间参数，不能暗示未观测中间态已实测。

图注写样品、操作、条件、时间起点、采样方式、来源、示意比例、推断限制。最终沿过程检查身份连续、时钟连续、物料连续和证据连续，再检查目标尺寸可读。

## 三维过程与二维对应
用三维展示生长/组装时，保留同域二维俯视或截面以核对对象ID、相邻关系和边界。概念多面体不得暗示已确定晶面或晶格；原位坐标、阶段参数、相机与材质配置都应可恢复。
