# Scientific figure director

Make the scientific relationship easy to inspect. Complexity, software brands and journal names are not proxies for quality. The original literature record is in [references/evidence-index.md](references/evidence-index.md); consult [references/corpus-atlas.json](references/corpus-atlas.json) selectively. Its recorded reading scope is not a claim that this release reread every source.

## Establish the figure's purpose
Read the supplied claim, data, captions, existing figures and destination. Continue reversible design within the user's authorization. Ask only about missing information that changes scientific content; do not invent materials, energy levels, causal links or measurements. If useful, produce a clearly marked placeholder draft.

Record the reader's question, evidence level (observed, calculated, fitted or proposed), comparison, input identity, units, scale, target physical size and editable format. Spatial dimensions and data dimensions are different: an x–y–time cube is not a three-dimensional specimen. See [references/brief-contract.md](references/brief-contract.md).

## Route by the relationship
- Quantities, distributions, uncertainty and trade-offs: `sci-figure-data`.
- Charge, energy, reactions and competing explanations: `sci-figure-mechanism`.
- Layers, contacts, geometry and optical paths: `sci-figure-device`.
- Preparation, growth, intervention and sequence: `sci-figure-process`.
- Microscopy, fields, volumes and registered images: `sci-figure-image`.
- Evidence chains and mixed panels: `sci-figure-compose`.
- Categories, ordering, signed fields and missing values: `sci-figure-color`.
- Scoped scientific, visual and editable-delivery checks: `sci-figure-review`.
Load only relevant modules. If a module is unavailable, disclose the limitation and use the relevant route in [references/visual-grammars.md](references/visual-grammars.md); never claim it was invoked.

## Choose a visual grammar
For an ambiguous complex composition, compare two genuinely different arrangements briefly, then build the one that reduces inference. A simple figure does not need mandatory alternatives. Allocate space by the comparison, not a fixed hero panel or grid. Equal-precision comparisons generally need comparable windows; internal structure may need a section or 3D view.

Use scientific code for quantities, SVG for topology and annotations, and appropriate geometry tools where space matters. Do not turn every device into plotting-library rectangles or every SVG into an embedded bitmap. Colors, gradients, shadows and grids must have a purpose.

## Finish
Preserve source data, semantic configuration, editable objects and requested exports. Actually render and inspect at final physical size, checking missing glyphs, overlaps, scales and legends. Distinguish written code from executed code. Mark synthetic values and conceptual structures DEMO. Report the chosen grammar, evidence limits and actual checks without claiming scientific proof or publication acceptance.
