# 作图合同

这是从用户材料中提取的工作记录，不是每次要求用户填写的问卷。缺失项写unknown；可以先做带占位的布局，不能凭空生成科学内容。

| 项目 | 记录 |
|---|---|
| 一句话主张 | 读者应看懂的关系或比较 |
| 证据层级 | 直接观测 / 模型或重建 / 拟合 / 假说 |
| 输入 | 文件、来源、变量、单位、样本与批次 |
| 比较 | 条件、基线、反事实、处理前后 |
| 尺度 | 空间/时间/能量/反应坐标；已知尺寸或非按比例 |
| 颜色 | 实体、条件、状态、场量各自登记 |
| 输出 | 最终宽高、用途、期刊与阶段、可编辑格式 |
| 操作记录 | 过滤、归一化、阈值、裁切、插值、外推 |
| 未知 | 尚不支持的细节与图中如何标记 |

“材料生长调控，高级一点”：已有原位时间序列时可用过程带、同位置结构图和量化曲线。只有终态测量时，中间过程只能标为推断或假设，不能补成直接观察。几何影响传热或应力时增加局部3D。

“器件性能对比”：区分独立器件与重复测量；保留原始点、分布、性能权衡和外推区间。单均值比较无需让装置占半页；需要解释结构作用时增加剖面与独立能级图，能量轴不能当厚度。

交接包括：主张、视觉语法与选择理由、证据边界、文件关系、运行命令、已检验与未检验部分。图注解释颜色、箭头、单位、n、误差、比例和代表图选择规则。示例数据明确DEMO，不给无数据占位图编造P值或误差条。
