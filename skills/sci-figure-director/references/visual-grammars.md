# 按任务选择视觉语法

| 语法 | 适用 | 关键检查 |
|---|---|---|
| 极简比较 | 单一指标与清楚基线 | 可比统计量、直接标签 |
| 条件矩阵 | 多材料×多处理、同域多通道 | 共享轴、范围、缺测 |
| 因果/状态拓扑 | 激活、抑制、竞争、可逆过程 | 箭头含义、假说层级 |
| 能量景观 | 势垒、陷阱、跃迁 | E轴、状态坐标、数值来源 |
| 结构剖面 | 内部层序、通路与接触 | 比例、隐藏面、接触面 |
| 爆炸结构 | 装配和组成 | 拆开位移不是工作距离 |
| 体数据渲染 | 孔隙、拓扑、三维分布 | 传递函数、阈值、切面 |
| 操作—观察配对 | 微流控、制备、采样 | 位置与操作对应 |
| 时间/阶段带 | 动力学、生长、调控窗口 | 实际时间距/阶段含义 |
| 原图—推断—定量 | 分割、去噪、重建 | 原始图保留、选择规则 |
| 多尺度追踪 | 设备到材料到局部 | 尺度、ROI和位置对应 |
| 轨迹—分布—残差 | 模型或实验拟合 | 独立验证、误差定义 |
| 聚合网络/分组 | 脑网络、多组分连接 | 聚合定义、边权、交互 |
| 公式—矩阵—几何 | 物理与计算方法 | 符号、维度、零值含义 |

它们可组合，不是固定版式。3D和材质只在曲率、内部关系、光路或介质解释中有用时保留；统计量不由透视、发光或未经说明的面积变化表达。公式和细线也能产生清晰精确的高级观感。

复杂草案可比较两种结构不同的布局，按读者所需推断次数、定位准确度和成品可读性择优；不要只换配色当作两个方案。
