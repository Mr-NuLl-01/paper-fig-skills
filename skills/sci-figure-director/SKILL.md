# 科研图总导演

目标是让读者准确看懂科学关系，并愿意仔细看；不以复杂度、软件名或期刊品牌作为质量代理。89篇论文依据见 [references/evidence-index.md](references/evidence-index.md)，按需查完整记录 [references/corpus-atlas.json](references/corpus-atlas.json)，不要每次全量加载。

## 先判断，再制作

读取用户的数据、主张、图注、已有图和目标用途。已有授权下继续完成可逆设计，不为换配色或选软件反复请示。信息不全时先做标有占位的草案；只有影响科学内容的问题才追问，不补造未知材料、能级、因果或数据。

用 [references/brief-contract.md](references/brief-contract.md) 记录一句主张、观察/推断/假说、比较对象、尺度、输入与成品尺寸。区分空间维度与数据维度，例如x-y-时间立方体不是三维样品。

| 读者要看懂什么 | 专业模块 | 优先表达 |
|---|---|---|
| 数值、分布、趋势、误差、权衡 | $sci-figure-data | 点/区间、曲线、条件矩阵、残差、时间窗 |
| 因果、反应、能量、载流子、状态 | $sci-figure-mechanism | 因果、能级、竞争路径、状态图 |
| 内部层序、接触、尺寸、光路 | $sci-figure-device | 平面、剖面、爆炸、局部3D、正交视图 |
| 生长、制备、调控、实验次序 | $sci-figure-process | 时间带、分支、条件—结果、操作配实证 |
| 显微、场、分割与重建 | $sci-figure-image | 同域对照、原图/推断分层、切面与量化 |
| 多面板如何支持主张 | $sci-figure-compose | 证据链、矩阵、跨尺度、并行比较 |
| 颜色如何表达数据 | $sci-figure-color | 身份、顺序、发散、周期、缺测 |
| 是否可以交付 | $sci-figure-review | 科学语义、可读性、可编辑性分开检查 |

只加载相关模块。子技能不可用时执行本合同和 [references/visual-grammars.md](references/visual-grammars.md) 的对应路线，明确工具限制，不假装调用成功。

## 避免再次成为模板

复杂或风格不确定时快速做两种结构不同的草图，按“哪一种减少读者推断”择优后完成；不把备选设计变成等待投票的必经关卡。简单单图直接制作。

按视觉任务分配面积，不要求每图都有大hero。等精度比较用等大面板；内部关系用剖面或3D；同图允许不同背景。颜色数量、渐变、阴影、曲线箭头、网格和字体依据科学用途与目标规范判断，不能只因“顶刊风”套用固定限制。

允许混合工具：科学程序生成数据层，SVG保存拓扑和注释，分子/晶体/体数据使用领域工具，几何需要时使用Blender/CAD。不为统一后端把每个器件画成Matplotlib矩形，也不把SVG变成单张嵌入位图。

## 完成

保留数据来源、源文件、语义配置与导出图；含栅格数据时让标注保持矢量独立。渲染并按最终尺寸查看，修复遮挡、缺字、图例与尺度。工具无法运行时区别“源码已写”和“已运行”。示例数据与概念结构显式标DEMO，不混入科研结果。

说明采用的视觉语法、理由、证据边界和已做检查；不宣称自动检查证明机制正确或保证顶刊录用。
